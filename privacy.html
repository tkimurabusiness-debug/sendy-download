プライバシーポリシー

最終更新: 2026年7月26日 / 株式会社 Stock Value（以下「当社」）

1. 基本方針

Sendy（以下「本アプリ」）は、お客様のメッセージ本文・ログイン情報を、当社のサーバーへ送信しない設計です。 これは運用上の約束ではなく、そのような送信経路をアプリに実装していないという技術的な事実に基づきます。

2. 端末内にのみ保存される情報

次の情報は、お客様の Mac のアプリ用フォルダ内にのみ保存されます。当社はアクセスできません。

  • 各サービス（Messenger・LINE・LinkedIn・Gmail 等）のログイン情報。macOS の安全な保管領域（Keychain / safeStorage）で暗号化して保存します。
  • 受信・送信したメッセージ本文、添付ファイル、連絡先の表示名やアイコン。
  • 返信の下書き、予約送信、タグ、既読の状態などの操作履歴。

3. 外部に送信される情報（AI 機能を使うときだけ）

お客様が「返信案を生成」「文章を整える」などの AI 機能を実行したときに限り、対象の会話の内容が Google の生成AI（Gemini API）へ送信され、返信案の生成に使われます。

  • 送信されるのは、その操作の対象となった会話の内容だけです。他の会話やログイン情報は送信されません。
  • 当社は、その内容を受信・保存しません（お客様の端末から直接 Google の API へ送信されます）。
  • API 経由の入力はモデルの学習に使用されない条件で呼び出しています。詳細は Google の API 利用規約に従います。
  • AI 機能を使わなければ、外部へ送信される情報はありません。

4. 各サービスへの接続について

本アプリは、お客様が接続した各サービスへ、お客様本人として通信します（当社のサーバーを経由しません）。 Google アカウントとの接続には OAuth を使用し、お客様が許可した範囲（メールの読み書き等）のみアクセスします。 許可はいつでも Google アカウントの設定から取り消せます。

5. 不具合の記録

本アプリは、不具合の原因を追えるように「いつ・どの処理で失敗したか」を端末内に記録します。 この記録に会話の本文やログイン情報は含めません。詳しい記録を当社へ送るかどうかはお客様が選べます。

6. 利用状況の記録（アプリの改善のため）

アプリを良くするために、どの画面がどれくらい使われているか、どこで失敗しているかを当社へ送ります。 初回起動時に画面でご案内し、設定画面からいつでも止められます。

送る内容は次のものだけです。

  • 端末ごとのランダムな番号（お名前・メールアドレス・端末の固有番号とは無関係で、お客様を特定できません）
  • アプリの版、OS の版、言語の設定
  • 操作の種類（例: アプリを起動した、どの画面を開いた、返信案を採用した）と、その時刻

次のものは送りません。

  • 会話の本文、件名、相手のお名前、メールアドレス、電話番号
  • ログイン情報（パスワード、アクセストークン、APIキー）
  • お客様が入力した文章、添付ファイル

これは運用上の約束ではなく、仕組みで守っています。受け取り側のデータベースには、 会話の本文やログイン情報を保存する欄そのものがありません。欄が無いため、 万一送られてきても保存できません。

7. データの削除

アプリ内の設定から「取り込みデータをやり直す」を実行すると、取り込み済みの会話データを削除できます。 アプリ自体を削除する場合は、アプリケーションフォルダの Sendy と、 ~/ライブラリ/Application Support/Sendy フォルダを削除してください。すべての保存データが消えます。

8. 第三者提供

当社は、お客様の会話内容やログイン情報を保有しないため、第三者へ提供することはできません。

9. お問い合わせ

本ポリシーに関するお問い合わせは、株式会社 Stock Value（info@stockvalue.co.jp）までご連絡ください。

10. 改定

本ポリシーを変更する場合は、本ページに変更後の内容と最終更新日を掲示します。
