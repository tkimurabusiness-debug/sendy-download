返す作業を軽くする

  • AI の返信案

    返しそびれが無くなる

    相手との過去のやり取りと、あなた自身の言い回しを読んだ下書きが先に出ています。選んで、直して、送るだけです。

    もう少し詳しく

    使っているのは Google の Gemini です。設定に自分の API キーを貼ると動きます。キーが無いときや月の回数を使い切ったときは、あなたの Mac の中だけで作る簡単な下書きに自動で切り替わります。「AI が作った」と嘘をつくことはありません。

  • 日程の提案

    空いている時間を探しに行かない

    Google カレンダーの予定を見て、空いている時間だけを候補にした返事を作ります。予定と重なる枠は自動で外れます。

    もう少し詳しく

    カレンダーをつないでいないときは、あなたが決めた時間帯の中から候補を組み立てます。つないだ場合も、Sendy が読むのは「空いているか埋まっているか」だけです。

  • 文体と相手の記憶

    相手ごとに言い方が変わる

    誰と何を話したか、あなたがどんな言い方をする人かを覚えていて、下書きに反映します。毎回さかのぼる必要がありません。

    もう少し詳しく

    見ているのは、丁寧さ・一文の長さ・絵文字の使い方・実際の言い回しです。覚えている中身はアプリの「記憶」の画面でそのまま読めますし、消せます。

  • 未返信の絞り込み

    返す番の会話だけ残る

    最後の発言が相手で、決めた時間を過ぎた会話に印が付きます。印の付いた会話だけを一覧にできます。

    もう少し詳しく

    時間は1時間から30日まで選べます。はじめは24時間です。この機能は設定で入にしてから使います。

  • 予約して送る

    深夜に書いても朝に届く

    書いた返事が相手に届く時間を指定できます。予約した分は会話の上に並ぶので、取り消しもできます。

  • 定型文

    同じ文を打ち直さない

    よく使う返事を登録しておいて、会話の途中から呼び出せます。

  • キーボードで操作

    マウスに持ち替えない

    Cmd+K を押すと、会話も操作もその場で探せます。送信も接続先の切り替えも指を離さずにできます。

    割り当ての一覧

    会話と操作を探す
    Cmd+S
    会話の一覧を開く 閉じる
    Cmd+D
    AI のパネルを開く 閉じる

    下書きの種類を切り替える
    Cmd+Enter
    送る
    Cmd+1〜9
    接続先とフォルダを切り替える

窓口を1つにする

  • 1つの受信箱

    アプリを行き来しなくなる

    Messenger・LINE・Instagram・LinkedIn・Chatwork・メールを1つの画面で読み書きできます。Slack と Discord は Sendy の中で元の画面を開きます。

  • 既読の付き方

    読んだだけでは相手に伝わらない

    開いて読んでも、相手の画面に既読は付きません。返事を送ったときにだけ付きます。買った直後からこの設定です。

    もう少し詳しく

    これは全部の接続先に効きます。逆に「相手がいつ読んだか」を Sendy の中で見られるのは Messenger・LINE・Instagram の3つです。ほかのサービスは、そもそもその情報を外に出していません。

  • 同じサービスで複数

    仕事用と個人用を並べて置ける

    LINE とメールは、同じサービスのアカウントを複数つなげます。切り替えずに1つの一覧で読めます。

    もう少し詳しく

    複数持てるのは今のところ LINE とメールだけです。Messenger・Instagram・LinkedIn・Chatwork は1つずつです。

  • LINE の中身

    LINE を開き直さなくていい

    スタンプ・画像・引用返信・リアクション・送信取り消し・グループ・友だち一覧・相手の既読まで、Sendy の中でできます。

    まだできないこと

    アルバム、ノート、音声通話とビデオ通話、LINE の中の検索、受け取ったファイルの取り出しは、まだ Sendy の中ではできません。LINE 本体を開いてください。

  • フォルダ

    仕事と友達が混ざらない

    会話を自分で決めたフォルダに分けられます。Cmd+1〜9 で切り替わります。

  • 通知

    鳴らしたいものだけ鳴る

    接続先ごとに通知を切れます。アプリの中の未読の数字だけ消すこともできます。

  • 会話の書き出し

    やり取りを手元に残せる

    1つの会話を md・json・html・pdf で保存できます。添付ファイルごと zip にもできます。

    もう少し詳しく

    期間や件数で絞って書き出せます。複数の会話をまとめて書き出すこともできます。

  • Messenger の履歴

    暗号化された昔の会話も読める

    会話ごとに1回押すと、暗号化されたやり取りを取り込みます。取り込みはあなたの Mac の中だけで行います。

  • 自動で新しくなる

    入れ直さなくていい

    新しい版が出ると自動で取りに行き、Sendy を閉じたときに入れ替わります。

AI に渡す

  • MCP でつなぐ

    Claude Code に会話をそのまま読ませられる

    設定のボタン1つで、Claude Code・Claude Desktop・Codex に登録します。会話をコピーして貼る手間が無くなります。

    渡せる道具の一覧
    list_accounts
    つないでいるアカウントの一覧
    list_threads
    会話の一覧
    get_messages
    その会話のメッセージ
    search
    言葉で会話を探す
    send_reply
    返事を下書きとして積む

    つながるのは 127.0.0.1 の中だけです。外の機械からは開きません。

  • 会話から AI に聞く

    コピーして貼らなくていい

    会話の画面からそのまま AI に質問できます。渡す範囲は自分で選びます。返ってきた答えは、そのまま相手に送れます。

    もう少し詳しく

    調べものや、返し方に迷ったときの相談に向いています。何も選ばなければ会話の中身は渡りません。

  • 音声で入力

    打たずに返せる

    話した内容をその場で文字にして、下書きに入れます。

  • 文を整える

    雑に打っても送れる形になる

    思いついたまま打った文を、相手と場面に合った文に直します。書き直す前の文はそのまま残ります。

  • 自分の道具から叩く窓口

    自分で自動化を組める

    会話の読み取りと、下書きの投入を HTTP でできます。送信だけは必ず Sendy の中であなたが承認します。

    もう少し詳しく

    勝手に相手へメッセージが飛ぶことはありません。合言葉は MCP と同じものを使います。読み取りだけを許す使い方もできます。

  • 最近のファイル

    Finder を探しに行かない

    ダウンロード・デスクトップ・書類の新しいファイルが画面の左下に出ます。そこから会話へ直接引っ張れます。

    もう少し詳しく

    出るのは直近7日の中の新しい5件です。画像は中身が小さく見えるので、探し直さずに選べます。

  • スマホから開く

    Mac の前にいなくても読める

    Mac を親機にして、同じ Wi-Fi のスマホのブラウザから同じ受信箱を開けます。はじめは切ってあります。

    もう少し詳しく

    入にすると合言葉が出て、その合言葉でスマホと対をつくります。外出先から使うには、別に道を通す必要があります。
